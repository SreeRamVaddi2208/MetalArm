# Minimal redesign: flags

These are places where the build departs from the spec, or where the spec could not be followed as written. Each one says why and what was done instead. None of them touches the backend, the API contract, or the points, PR, streak or rank rules (`git diff origin/main -- backend ios` is empty).

| # | Spec | What was built | Why |
|---|---|---|---|
| 1 | Progress range control: 1M / 3M / 6M / 1Y / All | 3M / 6M / 1Y / All | The analytics API accepts only `3M`, `6M`, `Year` and `All` (`backend/app/api/routes/analytics.py`). A 1M range would mean computing on the client or changing the API, and both are out of scope. "1Y" is sent as the API's `Year`. |
| 2 | Onboarding path cards show the 3D path models | The same cards with no model; the selected card has the accent outline, accent-soft fill and a check | The 3D path models exist only in the iOS app. The web has no model assets. |
| 3 | App settings (sound, haptics, reduced motion) | Per device, kept in browser storage (`ma_celebration_mute`, `ma_haptics`, `ma_reduce_motion`) | The account API has no fields for them, and they are device comforts. This extends the pattern the celebration sound already used. Reduced motion also honours the system setting. |
| 4 | Picker "Recently used" | The account's own exercises from `GET /me/exercises`, most recent first | There is no separate recents endpoint. This list is the server's, not a client tally. |
| 5 | The spec's screen list | Four tabs that also hold the screens the spec didn't list: quests, duels, parties, rewards, rank trials, badges, character stats, import, programs, exercise and session detail, people, notifications, monthly summary, credits | No shipped feature was dropped. The map is in `frontend/DESIGN_SYSTEM.md`, and the old URLs redirect. |
| 6 | text-3 `#66666E` | `#6E6E76` | `#66666E` on surface-2 is 2.85:1. Placeholders sit on surface-2 (every input), so `frontend/tests/test_contrast.py` holds text-3 to 3:1 there. `#6E6E76` gives 3.21:1 and still reads as the faintest grey. |
| 7 | Tap targets of 48 px | 48 px for buttons, steppers, fields, rows and the set-type toggle; 44 px for icon buttons | The spec's own IconButton primitive is 44 px. `logging_e2e` checks both minimums on the live workout screen. |
| 8 | At most 3 type sizes per screen | Three content sizes on most screens: one title size, body and caption. The large display number appears only as a screen's hero (timer, set entry, points total, stat headline). Button labels use the label style and are counted as part of the control. | A screen with a hero number, section titles and body text would otherwise need four sizes. The design-system page shows the pairing. |
| 9 | PR celebration | A 2.5-second banner from the bottom, a PR pill on the set row, and the PR rows on the summary | The full-screen PR overlay is gone. Interrupting someone between sets is what the spec's reward-moment rule warns against. Rank-up keeps its overlay, with sequencing unchanged and only its surface restyled. |
| 10 | — (new behaviour) | After a set, focus moves to the next card that still owes sets, alternating within a superset | Only the focused card shows the entry panel (one accent action per screen). Without this, every new exercise would cost an extra tap. This only changes which card shows the entry panel, never what is logged. |
| 11 | Narrated film tours | `web_tour.mjs` and `overhaul_tour.mjs` were updated to the new routes and labels but **not re-recorded** | They need the narration audio assets (`scripts/demo/render_assets.mjs`). Their chapter scripts in `scripts/demo/*.json` still describe the five-tab app and need rewriting before the next film. |
| 12 | Share card | Unchanged layout; its dim, card and border colours now come from the new tokens, and its eyebrow is the accent | The old card read colours that no longer exist (`MUTED`, `PANEL`, a tier colour). It is an exported image, not a screen. |

> **Later:** the Library tab (7 Oct 2026) made it five tabs: Home, Train, Library, Progress, Profile. Programs, ready-made workouts and the exercise browser moved from Train to Library. See [`docs/library/FLAGS.md`](../library/FLAGS.md).
